# 在途 CRM 手机端可评审原型

直接打开 `index.html`。原型不依赖服务端、构建工具或网络资源。

可选验证：运行 `node --test prototype.test.mjs` 检查评审壳、页面数量与关键交互合同。

## 评审结构

- 左侧：14 个界面入口与已评审进度。
- 中间：可切换 375 × 667、390 × 844、430 × 932 的手机原型。
- 右侧：当前界面的评审目标、PRD 对照、关键边界、视觉参考和独立修改意见。
- 修改意见与“已评审”状态保存在浏览器 `localStorage`，可导出为 JSON。

## 页面清单

1. 事实工作台
2. 客户列表
3. 新增客户查重
4. 新增 / 编辑客户
5. 客户详情（资料、联系人、地址、业务线、沟通记录）
6. 手工新增沟通
7. 沟通记录列表
8. 沟通记录详情
9. AI 材料输入
10. AI 处理、失败恢复与客户匹配
11. AI 未确认草稿审核
12. 补充已有记录差异
13. 停用数据治理
14. 我的

## 建议走查路径

- 客户主路径：客户列表 → 新增客户 → 查重 → 客户表单 → 客户详情。
- 手工沟通：客户详情 → 新增沟通 → 保存正式记录 → 沟通详情。
- AI 沟通：工作台 → AI 整理材料 → 材料处理 → 客户选择 → 未确认草稿 → 确认正式记录。
- 版本与治理：沟通详情 → 补充材料 → 逐字段差异 → 新版本；客户或沟通列表 → 停用数据治理 → 恢复。

## 边界

原型只覆盖 CRM 一期客户事实、沟通事实、AI 草稿确认与治理。界面不包含销售额、漏斗、客户评分/等级/价值、风险、赢单概率、计划、任务、提醒、负责人、截止日期或 AI 销售建议。
